# XShield Roadmap

## Phase 1: MVP

- Monorepo project skeleton
- Manifest V3 extension
- Content script visible-user collection
- Rule engine and tests
- IndexedDB candidate pool
- Dashboard skeleton with candidates, rules, and block queue views
- Mock block executor adapter
- Rule management UI
- Whitelist, logs, settings, and local manual search
- Mock queue run, pause, resume, and retry handling

## Phase 2: Usability

- Rich rule editing
- Import and export rules
- Queue review workflow
- Better candidate deduplication
- Activity logs
- Optional extension popup routing for opening Dashboard directly

## Phase 3: Extension Hardening

- Permission minimization review
- Accessibility pass
- Error reporting inside local UI
- Manual confirmation flows for sensitive actions

## Phase 4: Community

- Contribution guide
- Issue templates
- Rule preset discussions
