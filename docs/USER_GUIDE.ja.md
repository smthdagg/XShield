# XShield ユーザーガイド（日本語クイックスタート）

> 詳細は [简体中文版](USER_GUIDE.zh-CN.md) または [English](USER_GUIDE.en.md) を参照してください（1.0.0+ 対応）。

## コアモデル

```
キーワード命中 → 返信を即座に非表示、投稿者は「トリガー記録」（= 保留リスト）へ
  → 自動ブロックキューに入り、30 分の猶予期間
      ├─ 放置 → 猶予後、レート制御に従って自動ブロック
      ├─ ホワイトリスト / 削除 → 永久除外してキューから退出
      └─ ブロック / 一括ブロック(N) → 即実行
  → 成功後は「ブロック済み」へ
```

キーワードライブラリは一つだけ（クラウド同期 + ローカルカスタムの 2 層）。

## クイックスタート

1. `chrome://extensions` → デベロッパーモード → `apps/extension/dist` を読み込み
2. x.com にログイン、ダッシュボード → Rules & sync → 今すぐ同期
3. X を閲覧：ヒットした返信は即非表示、投稿者は保留リストへ
4. トリガー記録ページで処理（ブロック / ホワイトリスト / 削除、一括ブロック）
5. ブロックログで統計と結果を確認（最新 300 件のページネーション + 検索）

## レート制御（トリガー記録ページで調整可能）

1 日上限 300（調整可）、バッチ 30（調整可、バッチ後に 15 分休止）、間隔 5 秒 ±5 秒（調整可）、429 で 15 分停止。

## コミュニティ共有ブラックリスト

同期時に `handles.txt` を自動ダウンロード。GitHub Token を設定すると自分のブロック帳簿をリポジトリへ統合し、全ユーザーと共有できます。Token なしはダウンロードのみ。
