# XShield 사용자 가이드 (한국어 빠른 시작)

> 자세한 내용은 [简体中文版](USER_GUIDE.zh-CN.md) 또는 [English](USER_GUIDE.en.md)을 참고하세요 (1.0.0+ 대응).

## 핵심 모델

```
키워드 적중 → 답글 즉시 숨김, 작성자는「트리거 기록」(= 보류 목록)으로
  → 자동 차단 대기열 진입, 30분 유예 기간
      ├─ 방치 → 유예 후 레이트 리밋에 따라 자동 차단
      ├─ 화이트리스트 / 삭제 → 영구 제외 후 대기열 퇴장
      └─ 차단 / 일괄 차단(N) → 즉시 실행
  → 성공 후「차단됨」으로 이동
```

키워드 라이브러리는 하나뿐 (클라우드 동기화 + 로컬 사용자 정의 2계층).

## 빠른 시작

1. `chrome://extensions` → 개발자 모드 → `apps/extension/dist` 로드
2. x.com 로그인, 대시보드 → Rules & sync → 지금 동기화
3. X 탐색: 적중된 답글 즉시 숨김, 작성자는 보류 목록으로
4. 트리거 기록 페이지에서 처리 (차단 / 화이트리스트 / 삭제, 일괄 차단)
5. 차단 기록 페이지에서 통계와 결과 확인 (최근 300개 페이지네이션 + 검색)

## 레이트 리밋 (트리거 기록 페이지에서 조정)

일일 한도 300 (조정 가능), 배치 30 (조정 가능, 배치 후 15분 휴식), 간격 5초 ±5초 (조정 가능), 429 시 15분 중지.

## 커뮤니티 공유 블랙리스트

동기화 시 `handles.txt` 자동 다운로드. GitHub Token 설정 시 자신의 차단 장부를 저장소에 병합해 모든 사용자와 공유할 수 있습니다. Token 없이는 다운로드만 가능합니다.
