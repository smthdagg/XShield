# XShield 使用说明书

X(Twitter) 评论垃圾拦截 + 一键拉黑 + 云端词库同步。触发与拉黑内核 1:1 移植自 X(Twitter) Comment Blocker 1.4.3。

---

## 一、安装

1. 构建扩展（或直接使用已构建的 `apps/extension/dist`）：

   ```
   corepack enable
   pnpm install
   pnpm build
   ```

2. Chrome 打开 `chrome://extensions` → 右上角开启**开发者模式** → **加载已解压的扩展程序** → 选择 `apps/extension/dist`。

3. 点击工具栏 XShield 图标 → **打开面板**。

> 拉黑功能依赖当前 Chrome 已登录 x.com（读取登录 Cookie）。未登录时只能过滤，不能拉黑。

---

## 二、快速上手（三步）

1. **确认词库**：面板 → **规则与同步** → 云端词库应显示数百个词（首次安装自动载入内置词库，无需联网）。
2. **浏览 X**：打开任意推文的评论区，命中关键词的回复会**立即隐藏**（默认）。
3. **处理名单**：面板 → **触发记录** → 对触发的用户：
   - 点卡片右上角勾选框选择，底部工具栏 **拉黑列表(N)**（3 秒内二次点击确认）
   - 或每张卡片右下角单独 **拉黑** / 加白 / 删除

拉黑成功后卡片按钮变为 **已拉黑**，触发记录**不会被删除**（可用「已拉黑」筛选项单独查看）；该用户同时出现在 **拉黑记录** 页，可在那里解除拉黑。

## 三、触发规则

### 词库来源（三层）

| 层级 | 来源 | 说明 |
|------|------|------|
| 云端词库 | GitHub `amahteru/x-comment-blocker` 的 `keywords.txt` | 6 小时自动同步 + 手动「立即同步」；GitHub API 失败走 jsDelivr CDN，再失败用扩展内置词库（开箱即用） |
| 我的词库 | 面板添加 / 页面右键选中文字 →「添加到屏蔽词」/ 导入 txt | 与云端词合并生效 |
| 内置兜底 | 扩展包内 `keywords.txt`（约 700 词） | 安装时自动种入，保证零网络可用 |

### 词格式

- 一行一条；普通词不区分大小写，子串匹配
- 正则写成 `/pattern/flags`，如 `/比.{0,3}她.{0,3}好/i`

### 自动拉黑词

在「规则与同步」页点 **自动拉黑词** 进入编辑模式，给词打勾 → 该词命中时用户**自动进入待拉黑队列**（无需手动）。

### 过滤开关（总设置）

| 开关 | 作用 |
|------|------|
| 启用过滤 | 总开关，关闭恢复所有帖子 |
| 命中处理方式 | **屏蔽回帖**（隐藏）或 **高亮**（黄底红字标记，不隐藏） |
| 同时过滤用户名 | 昵称含关键词也触发 |
| 仅对评论区应用过滤 | 只在单条推文页过滤回复，主页时间线不动作（默认开，防误伤） |
| 特殊字符 / 纯 emoji / Grok 卡 | 附加刷屏识别 |

## 四、拉黑（始终在 X 风控以内）

### 手动
- **单条**：触发记录卡片 → 「拉黑」（立即执行，成功后按钮变为「已拉黑」，记录保留）
- **批量**：勾选（或全选）→ 「拉黑列表(N)」→ 3 秒内再点确认 → 进入队列

### 自动
- 自动拉黑词命中 → 直接入队

### 记录流转保证
拉黑**从不删除触发记录**：一个用户的触发记录永远留在触发页，是否已拉黑由账本 `blockedUsersOnX` 决定，页面通过「拉黑 / 已拉黑」按钮态和「已拉黑」筛选呈现。拉黑失败（含账号已注销等永久失败）同样不动记录；解除拉黑会把用户移出账本，按钮恢复为「拉黑」。数据因此不会漂移——记录在哪，状态就在哪。

### 队列节流（不可配置，防风控）
- 每批 **30 个**，批后暂停 **15 分钟**
- 单次间隔 **5–10 秒随机**
- 429 限流 → 再停 15 分钟；失败重试 5 次（指数退避）
- 每日上限 **300**

拉黑记录页可看：今日已拉黑 / 队列剩余 / 暂停倒计时 / 已拉黑列表（可解除拉黑）。

## 五、把词库上传到自己的 GitHub

普通用户**只读**公共词库；填好以下信息即可把词库（云端 + 自定义全部）上传到**自己的仓库**：

1. 面板 → **脚本总设置**：
   - **GitHub Token**：需要 `repo` 权限的 Personal Access Token（GitHub → Settings → Developer settings → Personal access tokens 创建）
   - **我的仓库**：`你的用户名/仓库名`
   - **分支**：默认 `main`
2. 仓库里放一个 `keywords.txt`（没有会自动创建）
3. **规则与同步** → 我的词库 → **上传全部词库到我的 GitHub**
   - 上传内容 = 云端下载的词 + 自定义词，与仓库现有内容**合并且去重**，不会覆盖丢失
4. **让自己的仓库变成同步来源**：总设置 → 「云端词库仓库」填 `你的用户名/仓库名` → 之后「立即同步」和每 6 小时自动同步都从**你的仓库**拉取（留空则用上游公共仓库 `amahteru/x-comment-blocker`）。其他设备同样填你的仓库即可共享你的词库。

## 六、数据与隐私

- 全部数据在本地 `chrome.storage.local`，无后端、无账号
- 网络请求仅三种：公共词库文件拉取（GitHub/jsDelivr）、你主动点击的 GitHub 上传、你主动操作的 X 拉黑接口
- 屏蔽历史最多 5000 条；已拉黑名单最多 10000 个

## 七、常见问题

**Q：为什么看不到任何隐藏？**
1. 词库是否为空（规则与同步页看云端词数量）
2. 总设置「启用过滤」是否开启
3. 是否在主页时间线（默认仅评论区生效）
4. 刷新 X 页面（扩展重载后旧页面需刷新）

**Q：拉黑显示「无法获取身份凭证」？**
当前 Chrome 未登录 x.com，先登录再操作。

**Q：上传 GitHub 失败？**
检查 Token 权限（需 repo 写权限）、仓库格式 `owner/repo`、分支存在。

**Q：想先看看命中了什么再决定？**
总设置 → 命中处理方式 → 切「高亮」，命中帖子会黄底红字标记而不隐藏。
