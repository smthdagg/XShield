# XShield 使用說明

## 1. 安裝

1. 開啟 Chrome。
2. 前往 `chrome://extensions`。
3. 啟用「開發人員模式」。
4. 點選「載入未封裝項目」。
5. 選擇 `apps/extension/dist`。
6. 將 XShield 固定到 Chrome 工具列。

從原始碼建置：

```bash
corepack enable
pnpm install
pnpm build
```

建置完成後載入 `apps/extension/dist`。

## 2. 建立規則

在 Dashboard 的「規則」頁面建立關鍵字或正規表示式規則。

- `keyword`：一般關鍵字，一行一個。
- `regex`：正規表示式，一行一個。
- 比對欄位：使用者名稱、顯示名稱、個人簡介、貼文內容。
- 分數：命中後增加的風險分。

命中後，X 頁面中的相關貼文會變成淡黃色，使用者會進入候選池。

## 3. 複核候選使用者

在「候選使用者」中查看頭像、使用者連結、個人簡介、粉絲資訊和命中原因。確認目標後加入拉黑佇列；誤觸發使用者可加入白名單。

## 4. 執行拉黑佇列

- 「執行佇列」：依設定中的批次數量、間隔和模式執行。
- 「手動立即拉黑」：忽略時間間隔限制，但仍依批次處理。
- 「停止/執行」：控制自動佇列是否暫停。
- 「刪除選中」：從佇列移除。
- 「選中加白」：從佇列移除並加入白名單。

## 5. 匯出已拉黑使用者

在「已拉黑使用者」中選擇 TXT、CSV、JSON、NDJSON 或 SQL，然後匯出。

## 6. 真實拉黑提醒

真實拉黑依賴目前 Chrome 中的 X/Twitter 登入狀態。若 X 更新網頁接口、登入流程或 CSRF 策略，功能可能暫時失效。建議使用保守批次與至少 10 分鐘以上的間隔。
