# XShield 使用說明（繁體速覽）

> 完整教程請參閱 [简体中文版](USER_GUIDE.zh-CN.md) 或 [English](USER_GUIDE.en.md)。本頁僅為核心速覽（對應 1.0.0+）。

## 核心模型

```
關鍵詞命中 → 回覆立即隱藏，作者進入「觸發記錄」（= 待拉黑名單）
  → 進入自動拉黑佇列，30 分鐘緩衝期
      ├─ 不干預 → 緩衝期後按風控節奏自動拉黑
      ├─ 白名單 / 刪除 → 永久豁免並出隊
      └─ 拉黑 / 拉黑列表(N) → 立即執行
  → 成功後移入「已拉黑」
```

詞庫只有一個（雲端 + 本地自訂兩層），無「自動拉黑詞」之分。

## 快速上手

1. `chrome://extensions` → 開發人員模式 → 載入 `apps/extension/dist`
2. 登入 x.com；面板 → 規則與同步 → 立即同步
3. 瀏覽 X：命中的回覆立即隱藏，作者進入待拉黑名單
4. 觸發記錄頁處理名單（拉黑 / 白名單 / 刪除；全選批次拉黑）
5. 拉黑記錄頁查看統計與結果（最新 300 個分頁瀏覽 + 搜尋）

## 風控節奏（觸發記錄頁可調）

每日上限 300（可調）、每批 30（可調，批後歇 15 分鐘）、間隔 5 秒 ±5 秒（可調）、429 暫停 15 分鐘。

## 社區共享黑名單

同步時自動下載 `handles.txt`（共享拉黑名單）；填 GitHub Token 後可把自己的帳本合併共享給所有用戶。不填 Token 只下載。
