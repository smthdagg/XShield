# 项目主要功能与特点

我的 X 评论区终于干净了 —— 我给 X 做了一个开源的 AI 反垃圾浏览器扩展：**X护盾（XShield）** 🛡

它接入了 TypeSafe 的 System One 判定模型（Jev）：每扫到一条新回复，一次 API 调用并行回答三个问题 —— 属于哪类（黄推/诈骗/纯广告/人机/正常）、垃圾程度打分（0–3）、是不是垃圾（概率）—— 再结合你自己维护的词库命中情况，综合出最终结果。词库是人工维护的真值，模型犹豫时，听词库的。

---

## 一、判定过程全程可见

每条回复头顶都有一条实时状态条，判定结果、置信度、人工纠错按钮全部可见：

![评论区状态条全景](https://cdn.jsdelivr.net/gh/smthdagg/XShield@main/docs/images/promo/1-status-bars.png)

- 🟢 **正常 · 96%** —— 放行；
- 🔴 **AI·黄推 · 93%** —— AI 判定的四类垃圾（黄推/诈骗/纯广告/人机各有专属配色）；
- 🟡 **可疑 · 39%** —— 模型怀疑但置信度未达阈值，等你人工裁决。

词库命中则显示「关键字 · 内容屏蔽」，词库是人工维护的真值，命中即强信号。

## 二、自动隐藏，扫过即收

命中的回复先保持可见约 1.5 秒（让你看清它被判成了什么），随后**自动收起**为一行状态条 —— 收起的不是黑箱：判定结果、置信度、作者、原文摘要全写在上面。

![自动收起后的状态条](https://cdn.jsdelivr.net/gh/smthdagg/XShield@main/docs/images/promo/2-auto-collapsed.png)

翻回已读内容**不会重复判定**（判定记忆），隐藏状态保持，不浪费 token。

## 三、人工纠错，一键完成

每条状态条自带三个按钮：

- **显示/隐藏** —— 原地展开原文对照，再收起；
- **正常** —— 撤回隐藏 + 退出待拉黑 + 本会话不再判定该作者；
- **垃圾** —— 确认收起 + 以「人工确认」进拉黑队列。

## 四、学习回路：越用越准

你的每次「垃圾」确认都会被系统学习：后台自动从文本与作者昵称提取特征关键词，合并进「我的词库」。下次同类话术由关键字层**直接秒触发** —— 不等 AI、不花 token，同时作为 AI 判定的上下文信号。学习项写日志、可在词库里删除。

## 五、live 状态框：全透明

浏览时右上角常驻一块半透明状态框：已扫描回复数、拦截数（含占比）、最近判定延迟、**AI 费用（$ 实时累计）**；底行还有 tokens 总数、累计花费、每 1,000 条成本、平均每万字耗时。

![live 状态框](https://cdn.jsdelivr.net/gh/smthdagg/XShield@main/docs/images/promo/3-live-hud.png)

费用按 TypeSafe 官方定价计算：**$42/Btok，仅输入计费，输出免费** —— 实测每 1,000 条回帖约 $0.05。缓存命中不计费，关键字层触发零成本。

## 六、英文用户同样覆盖

内置 100+ 条英文垃圾模式（OnlyFans 导流、crypto giveaway、seed phrase 钓鱼、f4f、cash flip、betting tips、free robux、join my telegram……），中英文话术同样即时触发、同样作为 AI 上下文。

![英文界面总设置](https://cdn.jsdelivr.net/gh/smthdagg/XShield@main/docs/images/promo/4-en-settings.png)

## 七、默认最保守：仅隐藏，不拉黑

默认命中处理 = **只隐藏 + 记录**，绝不自动拉黑；需要自动拉黑的用户打开开关后，队列按类人节奏执行（每日上限 + 随机间隔 + 429 冷却）。

## 八、隐私是底线

- API Key 只存本地，判定请求由扩展后台直发 TypeSafe；
- 词库、记录、拉黑列表全部本地存储；
- 无遥测、无账号体系、MIT 开源可审计。

## 九、安装与使用 / Installation & Usage

### 安装 / Install

**中文**：

1. 打开 [GitHub Releases](https://github.com/smthdagg/XShield/releases)，下载最新的 `xshield-vX.Y.Z.zip`；
2. 解压 zip，得到一个内含 `manifest.json` 的文件夹；
3. Chrome 打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择该文件夹；
4. 固定到工具栏，登录 [x.com](https://x.com)。

**English**:

1. Grab the latest `xshield-vX.Y.Z.zip` from [GitHub Releases](https://github.com/smthdagg/XShield/releases) and unzip it;
2. Open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, pick the unzipped folder;
3. Pin the extension and log in to [x.com](https://x.com).

> 更新版本后请点「重新加载」并刷新所有 X 页面 / After updating, hit Reload and refresh all X tabs.

### 使用 / Use

**中文（开箱即用）**：

- 默认引擎为关键字触发、默认**仅隐藏**——打开任意推文评论区即自动工作；
- 每条判定回复头顶有状态条：点「显示/隐藏」展开对照，「正常」「垃圾」一键纠错；
- 想要更准的判定：总设置 → AI 判断引擎 → 填入 TypeSafe API Key → 测试连通 → 切换为 AI 智能判断；
- 点「垃圾」的每次确认都会自动学习特征词进词库，越用越准；
- 右上角状态框实时显示扫描/拦截/AI 费用；误判可在状态条一键恢复。

**English (works out of the box)**:

- Default engine is keyword matching, default action is **hide-only** — open any post's comment section and it just works;
- Every judged reply carries a status bar: use Show/Hide to compare, Normal/Spam to correct in one tap;
- For sharper judgement: Settings → AI engine → paste your TypeSafe API Key → Test connection → switch to AI judgement;
- Every Spam confirmation feeds the local learning loop — the blocklist gets smarter as you go;
- The live HUD tracks scans, catches, latency and running AI cost in real time.
